# Xiaomi Mi TV 4A (MiTV-MOOQ1, codename tarzan), Android TV 10, MediaTek MT9632, 1.8 GB RAM, 1080p.
# Firmware QTG3.200305.006.xxxx. Everything here is DISABLED for user 0, nothing is uninstalled.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh debloat.txt com.google.android.tvlauncher
#
# Gotcha: `pm disable-user` reaches /data/system/users/0/package-restrictions.xml about 10 s later.
# Reboot straight after disabling and the TV comes back with the packages enabled again. Wait first.
#
# Kept on purpose (checked with dumpsys package):
#   com.xiaomi.android.tvsetup.partnercustomizer  Bluetooth remote pairing (BleRcActivity) and the GlobalKey
#                                                 handler for the remote's Input button
#   com.mediatek.wwtv.tvcenter                    Live TV, and also the HDMI/AV window: can't be disabled
#   com.mediatek.tvinput, com.mediatek.hotkey.dispatcher, mitv.service, com.xiaomi.mitv.res
#   com.google.android.katniss                    voice search on the remote's mic button
#   com.google.android.apps.mediashell            Chromecast built-in
#   hbbtv_content_shell                           a vendor daemon, not a package; needs root
#
# Input button: the remote sends KEYCODE_TV_INPUT (178), and partnercustomizer opens the stock
# tvlauncher's InputsPanelActivity for it. With tvlauncher off that panel is gone, so the launcher's
# InputKeyService (an accessibility service) catches the key and shows its own inputs sidebar.
